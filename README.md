# ResumeVault AI

ResumeVault AI is a modern React application designed to help professionals manage their career history, tailor resumes for specific job descriptions, and track their job application pipeline all in one place.

## Features

- **The Vault**: A centralized database for your professional experiences. Maintain multiple variations of your bio, project details, and bullet points (e.g., Original, ATS-Optimized, Backend-Heavy) and seamlessly switch between them.
- **Tailor Workspace**: Paste a Job Description and watch as simulated AI agents (JD Researcher, Retriever, Writer, ATS Guard) analyze and tailor your resume specifically for the target role.
- **Application Tracker**: A drag-and-drop Kanban board to track your job applications through various stages (Discovered, Tailored, Applied, Interviewing).

## Technologies Used

- **React** (v18)
- **Vite** (Build tool)
- **Tailwind CSS** (Styling)
- **Lucide React** (Icons)

## Getting Started

### Prerequisites

- Node.js installed on your machine.

### Installation

1. Clone or download the repository.
2. Navigate to the project directory:
   ```bash
   cd D1006
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

To start the development server, run:

```bash
npm run dev
```

The application will typically be available at `http://localhost:5173`.

### Building for Production

To create a production build, run:

```bash
npm run build
```

You can preview the production build using:

```bash
npm run preview
```
